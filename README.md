# Gestión de Estudiantes en Java

## Descripción

Este proyecto consiste en una aplicación simple desarrollada en Java para representar y gestionar información básica de estudiantes.

El programa permite crear objetos de tipo Estudiante, almacenar datos como nombre, matrícula y calificación, mostrar su información y determinar si el estudiante se encuentra aprobado o no aprobado.

## Objetivo

Aplicar los conceptos fundamentales de la Programación Orientada a Objetos mediante la creación de clases, atributos, constructores, métodos e instanciación de objetos.

## Conceptos aplicados

- Creación de clases.
- Declaración de atributos.
- Uso de constructores.
- Instanciación de objetos.
- Creación y uso de métodos.
- Uso de estructuras condicionales.
- Documentación del código mediante comentarios.

## Clase Estudiante

La clase `Estudiante` contiene los siguientes atributos:

- `nombre`: almacena el nombre del estudiante.
- `matricula`: almacena la matrícula del estudiante.
- `calificacion`: almacena la calificación obtenida.

## Constructor

El constructor de la clase `Estudiante` permite asignar el nombre, matrícula y calificación al momento de crear cada objeto.

## Métodos

### mostrarInformacion()

Muestra en pantalla el nombre, matrícula y calificación del estudiante.

### verificarAprobacion()

Evalúa la calificación del estudiante. Si la calificación es igual o mayor a 70, muestra el estado "APROBADO". En caso contrario, muestra "NO APROBADO".

## Ejecución

En la clase principal `Main` se crean dos objetos de la clase `Estudiante` y se utilizan sus métodos para mostrar la información y verificar el estado de aprobación.
